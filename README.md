**Weather Control** lets you freely change the weather and fog in Twilight Princess.

### Features
- Switch between **Clear**, **Rainy**, and **Foggy** weather
- Adjust rain intensity
- Control fog with Near / Far modes, or completely disable it
- **Ignore Fog** toggle to preserve existing fog when switching weather
- **Force Clear Fog** option that bypasses all fog settings

All settings are available in the in-game mod menu and update in real time.
